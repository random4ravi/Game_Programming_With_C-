# 📌 Overview

**Car Dodge Game** is a **2D arcade-style endless car racing game** developed in **C++ using the SFML (Simple and Fast Multimedia Library)**.

The player controls a car and must avoid colliding with incoming enemy vehicles while trying to survive for as long as possible. The game includes **sound effects, collision detection, pause system, score tracking, and high score functionality**.

This project was developed as an **End-Term Academic Project** for learning **game development, object-oriented programming, and multimedia handling in C++**.

🚘 **Player Car Movement**  
Move the car smoothly using keyboard controls.

# ⚙️ Installation Guide

## Step 1: Install SFML

Download and install SFML:

🔗 https://www.sfml-dev.org/download.php

---

## Step 2: Clone Repository

```bash
git clone https://github.com/your-username/repository-name.git
```

---

## Step 3: Open Project

Open in any C++ IDE:

- Visual Studio
- CodeBlocks
- VS Code
- Dev C++
- CLion

---

## Step 4: Configure SFML

Link the required SFML libraries:

```bash
-lsfml-graphics
-lsfml-window
-lsfml-system
-lsfml-audio
```

Example compile command:

```bash
g++ cardodge_game.cpp -o game -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio
```

---

## ▶️ Run the Game

Execute the compiled file:

```bash
./game
```

Enjoy the gameplay 🚘🔥
